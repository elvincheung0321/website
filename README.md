# NASA API Website
Pick a date and see the images and explanations taken from the NASA API

### Demo Link:
https://elvincheung0321.github.io/website/

## How to run locally
1. Clone the repository:

```bash
git clone https://github.com/elvincheung0321/website.git
```

2. Install dependencies:

```bash
cd website
npm intall
```

3. Make the .env file:

```bash
cp .env.example .env
```
Edit the .env file to make sure you place your actual API key in there

4. Start the server

```bash
npm run dev
```
Open the url shown in the terminal to see the website fully functioning!
